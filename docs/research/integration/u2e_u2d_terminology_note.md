# U2-E clarification for U2-D terminology

This note clarifies status vocabulary without rewriting the historical U2-D decision or changing its selected scope.

- U2-D `QUALIFIED_INTERNAL_EVAL` on WHO/CDC records the owner's approved project use. The actual selected runtime role is `EXTERNAL_RETRIEVAL_RUNTIME`; it does not mean the cards became a benchmark or were used for TRAIN/DEV.
- `OWNER_ACCEPTED_SCOPE` records a project use decision. It does not mean an upstream license disagreement or source metadata uncertainty was resolved.
- U2-E TRAIN/DEV evidence is independently authored with `content_origin=PROJECT_OWNED_SYNTHETIC`. No WHO/CDC document content is included.
