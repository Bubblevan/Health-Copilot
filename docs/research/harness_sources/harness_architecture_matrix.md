## Matrix conclusion

The strongest cross-repository equivalences are provider separation, explicit tool boundaries, durable session facts, state-bound replay, and keeping scheduling outside the inner loop. The largest intentional differences are authority: Health Evidence, safety route, permission, memory and deterministic eval are narrower and more conservative. The useful missing primitives for later research are scoped worker lifecycles, richer tool/event interception and resumable operation state; none meets the H-Ref `ADOPT_NOW` threshold at this frozen stage.
