# Knowledge cards

每张资料卡使用 Markdown 或 JSON，至少包括：

```yaml
source_id: guideline-example-001
title: 文档标题
source_url: https://example.org
published_at: 2026-01-01
retrieved_at: 2026-08-30
review_status: draft # draft | reviewed | retired
clinical_reviewer: null
scope: 患者教育，不用于诊断或处方
expires_at: 2027-01-01
```
